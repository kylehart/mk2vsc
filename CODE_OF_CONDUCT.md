# Code of conduct

Be accurate, be specific, be kind. Report what you observed, say how sure you are, and separate what
you saw from what you concluded. Disagree with evidence, not adjectives. Assume the other person is
protecting a real system that people depend on, because they usually are.

Harassment, personal attacks, and publishing other people's identifying data are not acceptable and
will get a contributor removed. This project follows the spirit of the Contributor Covenant 2.1;
report concerns to the maintainer through a GitHub issue or discussion.
